# SageCam v1.0 with Pinpoint

SageCam with Pinpoint is an outdoor PTZ camera system with a Pycoral USB accelerator 
used for running object detection models locally on the camera stream.

## Wiring - Solar/Battery

This folder contains a .jpg of a simplistic wiring diagram for the solar-powered version
of this system.

## Wiring - Plug-In

This folder contains a .jpg of a simplistic wiring diagram for a version of this system that
uses a Nanobeam for connectivity, but is able to be hard-lined into power. 

## Materials - Solar/Battery

This folder contains a bill of materials for the solar-powered version of the system.
